\# Hackathon Activity Tracker



A simple and interactive Hackathon Activity Tracker web application built using HTML, CSS, and JavaScript. This project helps users track their progress during a hackathon by marking completed tasks and monitoring overall completion status in real time.



\---



\## Project Overview



The Hackathon Activity Tracker allows users to:



\* View a predefined list of hackathon tasks

\* Mark activities as completed using checkboxes

\* Track progress dynamically

\* Save progress automatically using Local Storage

\* Reset all progress instantly when needed



This project runs entirely in the browser and does not require any backend setup.



\---



\## Features



\* Interactive task checklist

\## How It Works



1\. The activity list loads automatically when the page opens.

2\. Users can check tasks as they complete them.

3\. The progress counter updates instantly.

4\. Task completion status is saved in the browser using Local Storage.

5\. Reloading the page keeps the saved progress.

6\. Clicking the Reset Progress button clears all selections.
